## 🚀 คำแนะนำ 3 ขั้นตอนในการนำขึ้น GitHub Pages

### ขั้นตอนที่ 1: สร้าง Repository บน GitHub
1. เข้าเว็บไซต์ [github.com](https://github.com) แล้วเข้าสู่ระบบ
2. กดปุ่ม **New** (หรือเครื่องหมาย `+` มุมขวาบน) เพื่อสร้าง Repository ใหม่
3. ตั้งชื่อ Repository (เช่น `lawyer-web`) แล้วเลือกเป็น **Public**
4. กดปุ่ม **Create repository**

### ขั้นตอนที่ 2: อัปโหลดไฟล์ขึ้น Repository
- **วิธีที่ A (ผ่านหน้าเว็บแบบง่ายที่สุด - แนะนำ)**:
  1. ในหน้า Repository ที่เพิ่งสร้าง ให้คลิกลิงก์ **"uploading an existing file"**
  2. ลากไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้ (`index.html`, `about.html`, `services.html`, `booking.html`, `contact.html`, โฟลเดอร์ `admin/`, และโฟลเดอร์ `assets/`) ไปวางในหน้าเว็บ GitHub
  3. รอให้อัปโหลดครบ แล้วกดปุ่มสีเขียว **Commit changes**
- **วิธีที่ B (ผ่านคำสั่ง Git CLI)**:
  ```bash
  git init
  git add .
  git commit -m "Initial commit for GitHub Pages"
  git branch -M main
  git remote add origin https://github.com/<your-username>/<your-repo-name>.git
  git push -u origin main
  ```

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages
1. ไปที่แท็บ **Settings** ในหน้า Repository ของคุณ
2. ที่เมนูด้านซ้าย ให้คลิกหัวข้อ **Pages**
3. ใต้หัวข้อ **Build and deployment** > **Branch**:
   - เลือก Branch: `main`
   - เลือก Folder: `/ (root)`
4. กดปุ่ม **Save**
5. รอประมาณ 1 - 2 นาที GitHub จะสร้างลิงก์เว็บไซต์ให้ เช่น:
   ```text
   https://<your-username>.github.io/<your-repo-name>/
   ```
   สามารถคลิกเข้าชมเว็บไซต์ได้ทันทีทุกที่ทั่วโลก!
